MAITIHUB24 - FINAL MOVIE SHARE / OG SYSTEM

1. Upload and replace the repository files with the contents of this ZIP.
2. Keep the repository's GitHub Pages source on the main branch (root folder).
3. After uploading, open GitHub -> Actions and wait for "Generate Movie Share Pages and Sitemap" to finish successfully.
4. Every future movie must be added to movies.json with a unique id, title, image filename, and (if applicable) destination link. Upload the poster image file too.
5. A push changing movies.json automatically generates /movie/MOVIE-ID/ with that movie's Open Graph/Twitter poster metadata and refreshes sitemap.xml.
6. Share the generated URL: https://maitihub24.dpdns.org/movie/MOVIE-ID/
7. Legacy query URLs such as https://maitihub24.dpdns.org/?movie=MOVIE-ID remain supported by the homepage movie loader, but social crawlers may only see the homepage OG image on those query URLs. Use /movie/MOVIE-ID/ for per-movie social previews.

Important: Social platforms cache previews. After publishing, use their link preview debugger/refresh tools where available, or wait for their cache to expire.
